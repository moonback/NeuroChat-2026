# 🚀 Guide Rapide - Contrôle du Navigateur

## Activation

1. **Activez le contrôle** : Cliquez sur le bouton "Contrôle inactif" en haut à droite
2. Le bouton devient **vert** : "Contrôle actif" ✅
3. **Parlez à votre assistant** !

## Commandes Simples

### 🌐 Ouvrir des Sites

Dites simplement :
- **"Va sur Google"**
- **"Ouvre YouTube"**
- **"Va sur Wikipedia"**

Sites reconnus automatiquement :
- google, youtube, facebook, twitter, instagram
- linkedin, wikipedia, amazon, netflix, spotify

### 🔍 Rechercher sur Google

Dites :
- **"Cherche la météo à Paris"**
- **"Recherche des recettes de gâteau"**
- **"Trouve les actualités du jour"**

### 📱 Exemples Complets

```
Vous : "Ouvre YouTube"
Assistant : "Je t'ouvre YouTube tout de suite."
→ Une fenêtre s'ouvre avec YouTube

Vous : "Cherche la météo"
Assistant : "Je regarde ça pour toi."
→ Google s'ouvre avec la recherche météo

Vous : "Va sur Netflix"
Assistant : "D'accord, j'ouvre Netflix."
→ Netflix s'ouvre dans la fenêtre
```

## 🎯 Fenêtre du Navigateur

Quand l'assistant ouvre un site :
- Une **fenêtre intégrée** apparaît
- Vous pouvez **naviguer normalement** dedans
- Utilisez les **boutons** en haut pour :
  - ⬅️ Retour
  - ➡️ Suivant
  - 🔄 Actualiser
  - 🔗 Ouvrir dans un nouvel onglet
  - ❌ Fermer

## ⚠️ Important

- Le contrôle doit être **activé** (bouton vert)
- Parlez **clairement** et **distinctement**
- Utilisez les **formulations suggérées**
- Certaines actions nécessitent une **confirmation**

## 🆘 Problèmes ?

**L'assistant ne répond pas ?**
- Vérifiez que le contrôle est activé (bouton vert)
- Réessayez avec une formulation différente
- Exemple : "Va sur Google" au lieu de "Peux-tu ouvrir Google"

**La fenêtre ne s'ouvre pas ?**
- Rechargez la page (F5)
- Vérifiez la console (F12) pour les erreurs
- Assurez-vous que JavaScript est activé

**L'assistant ne comprend pas ?**
- Utilisez les formulations exactes suggérées
- Parlez plus lentement
- Répétez la commande

## 💡 Astuces

1. **Soyez direct** : "Va sur YouTube" plutôt que "Est-ce que tu peux m'ouvrir YouTube s'il te plaît"
2. **Un site à la fois** : Attendez que le site s'ouvre avant de demander autre chose
3. **Utilisez les raccourcis** : "google" au lieu de "google.com"
4. **Confirmez les actions** : Quand une fenêtre de confirmation apparaît, lisez-la attentivement

## 🎉 C'est tout !

Vous êtes prêt à utiliser le contrôle du navigateur. Amusez-vous bien ! 🚀
